# GLP-1 RA in Type 2 Diabetes — Trial Watch

Tracking repository for the endocrinology group's quarterly pipeline review on **GLP-1 receptor agonists in type 2 diabetes**.

## Purpose

This repository captures the late-stage (Phase 3) recruiting landscape of GLP-1 receptor agonist trials in adults with type 2 diabetes, as retrieved from ClinicalTrials.gov. It serves as a durable record of:

- Currently recruiting studies of GLP-1 receptor agonists in adults with type 2 diabetes
- The Phase 3 trials with the largest planned enrollment, with their sponsor, phase, planned enrollment, and primary completion date
- Aggregate breakdowns of the search population by phase and by sponsor class

## Contents

- **Tracking issues** — one per selected Phase 3 trial (NCT ID in the title, with sponsor/phase/enrollment/completion date in the body)
- **Parent summary issue** — overview with the phase and sponsor-class breakdowns posted as a comment

## Search scope

- Condition: Type 2 Diabetes
- Intervention: GLP-1 receptor agonist
- Status: Recruiting
- Phase 3 trials with the largest planned enrollment selected for tracking
